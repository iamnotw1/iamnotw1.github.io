GymLog App

A native Android application built to track workout routines, sets, and fitness progress. Implements a robust local database for offline support and follows clean architecture principles using the MVVM design pattern.

  • Kotlin
  • Jetpack Compose
  • Room DB

HTTP File Downloader

A high-performance command-line utility that accelerates large file downloads. Built from scratch using low-level network sockets, it utilizes chunked HTTP requests and advanced thread synchronization to download parts concurrently.

  • Low-level Sockets
  • Threading
  • Networking

An interactive typing speed test application for Android devices. Features real-time Words Per Minute (WPM) calculation, accuracy tracking, and dynamic UI state updates to provide instant feedback to the user.

  • Kotlin
  • Jetpack Compose
  • Android SDK
  • State Management
